# 1. Conceito central da interface

A interface precisa responder 5 perguntas:

## 1. O que a empresa faz todo dia?

Rotinas, processos, tarefas, setores e pessoas.

## 2. Onde ela perde tempo, dinheiro e controle?

Retrabalho, gargalos, atraso, erro humano, planilhas e dependência de gente específica.

## 3. O que pode ser automatizado com IA?

Resumo, classificação, resposta, alerta, cobrança, relatório, tarefa, documento, atendimento e decisão assistida.

## 4. Quais ferramentas precisam conversar?

Google, RD Station, HubSpot, Bitrix24, ERP, WhatsApp, CRM, n8n, ClickUp, Notion, planilhas, banco de dados, financeiro, BI etc.

## 5. Qual automação gera mais economia primeiro?

Prioridade, impacto, esforço, risco e ROI.

Essa interface não é “bonitinha”.
Ela é um **raio-X com calculadora e bisturi**.

# 11. Tela 6: Matriz de Automação

Essa é a tela da decisão.

## Objetivo

Pontuar rotinas e priorizar o que automatizar primeiro.

## Critérios

| Critério                |            Peso |
| ----------------------- | --------------: |
| Frequência              |           1 a 5 |
| Tempo gasto             |           1 a 5 |
| Volume                  |           1 a 5 |
| Custo                   |           1 a 5 |
| Erro humano             |           1 a 5 |
| Impacto no cliente      |           1 a 5 |
| Facilidade técnica      |           1 a 5 |
| Dados disponíveis       |           1 a 5 |
| Integrações disponíveis |           1 a 5 |
| Risco                   | 1 a 5 invertido |
| Potencial de IA         |           1 a 5 |
| ROI esperado            |           1 a 5 |

## Fórmula conceitual

```text
Score de Automação =
Impacto + Frequência + Tempo + Custo + Erro + Potencial IA + Viabilidade
-
Risco + Complexidade
```

## Classificação

```text
80 a 100: P0 - automatizar primeiro
60 a 79: P1 - alta prioridade
40 a 59: P2 - médio prazo
20 a 39: P3 - baixa prioridade
0 a 19: Não automatizar agora
```

## Tela visual

```text

              │   Cobrança | Follow-up | Relatório
              │
Impacto médio │        P1/P2: Planejar
              │
Impacto baixo │        P3: Depois
              └────────────────────────────
                Baixo esforço       Alto esforço
```

# 33. Como a interface vende a fábrica

A interface tem que gerar 3 coisas:

## 1. Clareza

“Agora eu sei onde minha empresa perde tempo.”

## 2. Prioridade

“Agora eu sei o que automatizar primeiro.”

## 3. Dinheiro

“Agora eu sei quanto isso pode economizar.”

Se a interface não gera essas 3 sensações, ela é só painel bonito. Bonito sem venda é quadro na parede. A gente quer máquina.
