# Template: Marketing Factory

## O que cria
Fábrica de campanhas: funil, analytics, criativos, segmentação, automação de ads.

## Quando usar
- Campanhas recorrentes com públicos similares
- A/B testing de criativos em escala
- Funil de conversão multi-etapa
- Relatórios de ROAS automatizados

## Produtos típicos
- Campanha Meta Ads para hotelaria
- Sequência de email marketing
- Landing page + pixels + CRM
- Dashboard de ROI por canal

## Stack recomendada
- **Frontend:** Next.js + Tailwind + shadcn/ui
- **Analytics:** Google Analytics 4 + Meta Pixel
- **CRM:** HubSpot / Mailchimp / ActiveCampaign
- **Ads:** Meta Marketing API + Google Ads API
- **Database:** Supabase (PostgreSQL)

## Dependências
- Conta Meta Business verificada
- Pixel Meta instalado
- API keys de plataformas de ads

## Riscos
- R1: Conta de ads suspensa por política
- R2: Custo de aquisição inesperado
- R3: Dados de pixel incompletos

## Checkpoints
- CP-1: Público segmentado validado?
- CP-2: Criativos aprovados?
- CP-3: Pixel disparando corretamente?
