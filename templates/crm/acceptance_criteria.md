# Critérios de Aceitação — CRM MVP

1. **Cadastro de Contas** — O usuário pode criar, listar, editar e inativar contas.
2. **Cadastro de Contatos** — O usuário pode adicionar contatos vinculados a uma conta.
3. **Pipeline de Vendas** — O sistema deve exibir oportunidades em um funil com pelo menos 3 estágios (Prospect, Negociação, Fechamento).
4. **Responsividade** — As telas devem funcionar em desktop e dispositivos móveis.
5. **Persistência** — Os dados devem ser salvos localmente (mock) ou em API de teste, permitindo edição e exclusão.
6. **Notificações** — O usuário deve receber feedback visual ao criar ou editar registros.
7. **Segurança** — Não exibir dados sensíveis sem autenticação (para MVP usar autenticação mock ou desativar dados sensíveis).
8. **Relatórios básicos** — Visualizar métricas de contas ativas, oportunidades abertas e valores em negociação.
