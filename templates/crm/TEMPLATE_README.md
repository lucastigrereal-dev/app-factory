# Template: CRM

Este template auxilia na criação de um **Customer Relationship Management** (CRM) básico para gerir leads e clientes. Fornece um blueprint estrutural, plano de frontend e critérios de aceitação para a primeira versão do CRM.

## Estrutura

* **product_blueprint.yaml** — Define entidades principais (contas, contatos, oportunidades), relacionamento entre elas e campos mínimos.
* **frontend_plan.template.md** — Sugere arquitetura de componentes e telas (lista de clientes, detalhes, funil de vendas).
* **acceptance_criteria.md** — Lista de requisitos para aprovação do MVP do CRM.

Personalize esse template conforme os processos de vendas da empresa.
