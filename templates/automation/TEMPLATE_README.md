# Template: Automação

Este template destina‑se à criação de especificações de workflow de automação. Ele contém um arquivo de especificação de workflow e critérios de aceitação. Use-o quando for necessário automatizar uma rotina repetitiva ou integrar ferramentas.

## Estrutura

* **workflow_spec.template.md** — Modelo para descrever o fluxo de automação, incluindo gatilhos, passos, integração com APIs, lógica de decisão e ações finais.
* **acceptance_criteria.md** — Lista de critérios necessários para que o workflow seja aprovado para produção (incluindo logs, manejo de erros e aprovação humana).

Siga as instruções dos arquivos para preencher as seções com detalhes do fluxo específico.
