# Template: Dashboard Analítico

Este template oferece uma base para construir um dashboard que exibe métricas e visualizações de dados de um produto ou operação. Inclui um blueprint de páginas de dashboard, critérios de aceitação e instruções de implementação.

## Estrutura

* **product_blueprint.yaml** — Descreve widgets principais (gráficos de linha, barras, tabelas) e as métricas que devem ser apresentadas.
* **frontend_plan.template.md** — Recomenda bibliotecas de visualização (Chart.js, D3) e práticas de design de dashboards.
* **acceptance_criteria.md** — Define condições para considerar o dashboard pronto.
