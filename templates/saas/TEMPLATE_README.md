# Template: SaaS MVP

Este template orienta a criação de um MVP para um Software as a Service (SaaS). Fornece blueprint de funcionalidades básicas, plano de frontend, plano de backend e critérios de aceitação.

## Estrutura

* **product_blueprint.yaml** — Lista de funcionalidades mínimas (autenticação, cadastro, dashboard, billing básico).
* **frontend_plan.template.md** — Sugestão de stack (Next.js, Tailwind) e estrutura de páginas.
* **backend_plan.template.md** — Estrutura de API (REST ou GraphQL), modelos de banco de dados e serviços.
* **acceptance_criteria.md** — Requisitos para considerar o MVP pronto.
