# Template: Content Factory

## O que cria
Fábrica de conteúdo: calendário editorial, posts, SEO, publicação multi-plataforma.

## Quando usar
- Produção de conteúdo em escala
- Calendário editorial automatizado
- SEO + publicação social integrada
- Reuso de conteúdo entre canais

## Produtos típicos
- Pipeline: ideia → post Instagram + blog + newsletter
- Calendário editorial com aprovação
- SEOgram automatizado
- Repurpose de vídeo para short

## Stack recomendada
- **CMS:** WordPress / Ghost / Notion
- **SEO:** Ahrefs API + SurferSEO
- **Social:** Publisher OS (BullMQ + n8n)
- **AI:** Claude / GPT-4 para drafts
- **Database:** Supabase

## Riscos
- R1: Conteúdo genérico se over-automatizado
- R2: Violação de copyright em imagens
- R3: Algoritmo muda e estratégia obsoleta

## Checkpoints
- CP-1: Calendário aprovado?
- CP-2: Conteúdo humanizado?
- CP-3: SEO score > 70?
