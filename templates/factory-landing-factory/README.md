# Template: Landing Factory

## O que cria
Landing pages otimizadas: conversão, SEO, speed, A/B test.

## Quando usar
- Campanha pontual com objetivo claro
- Lançamento de produto/serviço
- Captura de leads via anúncio
- Página de venda simples

## Produtos típicos
- Landing para pacote de collab hotel
- Página de captura para webinar
- Venda de infoproduto
- Inscrição em lista de espera

## Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind + shadcn/ui
- **Analytics:** Google Analytics 4 + Meta Pixel
- **Forms:** React Hook Form + Zod
- **Deploy:** Vercel

## Riscos
- R1: CLS ruim = penalidade Google
- R2: Formulário quebrado = leads perdidos
- R3: Mobile não otimizado = bounce alto
