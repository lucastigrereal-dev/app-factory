# Critérios de Aceitação — Landing Page

Para que a landing page seja considerada pronta para lançamento, ela deve atender aos seguintes critérios:

1. **Responsividade** — A página deve se adaptar a telas de desktop, tablet e mobile sem quebra de layout.
2. **Velocidade de carregamento** — O tempo de carregamento inicial deve ser inferior a 2 s em conexões 4G.
3. **Acessibilidade** — Pontuação mínima de 90 no Lighthouse para acessibilidade; foco visível; textos alternativos para imagens.
4. **Consistência visual** — Uso das cores e tipografia conforme guia de estilo da marca.
5. **Formulários funcionais** — Campos de captura de leads devem validar entradas e exibir mensagens de erro amigáveis.
6. **Links corretos** — Todos os botões e links devem redirecionar para as seções ou páginas corretas.
7. **SEO básico** — Títulos, descrições e tags meta configurados; URL legível.

Cumpra todos os itens acima e obtenha aprovação das equipes de Marketing e UX antes de publicar.
