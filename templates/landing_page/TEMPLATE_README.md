# Template: Landing Page

Este template fornece uma estrutura inicial para uma landing page simples de marketing. Ela inclui uma blueprint YAML descrevendo seções, um plano de frontend e um conjunto de critérios de aceitação. Personalize conforme a identidade visual da marca e os objetivos de captação de leads.

## Estrutura

* **product_blueprint.yaml** — Estrutura hierárquica de páginas e seções (hero, features, call‑to‑action, depoimentos).
* **frontend_plan.template.md** — Instruções sugeridas para implementar a landing page (HTML/React, estilos, animações).
* **acceptance_criteria.md** — Lista de requisitos funcionais e não funcionais que a página deve atender.

Utilize esse template como ponto de partida. Ajuste o conteúdo e as seções conforme o briefing do projeto.
