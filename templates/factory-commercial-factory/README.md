# Template: Commercial Factory

## O que cria
Fábrica comercial: SDR, CRM, leads, pitch, propostas, follow-up.

## Quando usar
- Processo de vendas repetitivo
- Qualificação de leads em escala
- Pipeline comercial visual
- Propostas automatizadas

## Produtos típicos
- CRM para hotelaria
- Qualificador de leads via WhatsApp
- Gerador de propostas PDF
- Dashboard de pipeline comercial

## Stack
- **Frontend:** Next.js + Tailwind
- **CRM:** Supabase + n8n
- **Comunicação:** WhatsApp API + Email
- **Docs:** PDF-lib.js / Puppeteer

## Riscos
- R1: Lead qualificado perdido
- R2: Follow-up esquecido
- R3: Proposta sem aprovação jurídica

## Checkpoints
- CP-1: Lead scoring definido?
- CP-2: Template de proposta aprovado?
- CP-3: Pipeline com > 3 estágios?
